# Changelog

## KOS 1.0

- Added Debian `bookworm` AMD64 Live Build and hybrid ISO configuration
- Added Calamares graphical disk and account installer
- Added custom XFCE KOS desktop theme and wallpaper
- Added KOS Home, Browser, YouTube, AI, Settings, Store, Update, Files,
  Terminal, and System Monitor entry points
- Added UFW baseline, Bluetooth, PipeWire, printing, USB, archive, media,
  and development packages
- Added Mesa/Vulkan, Lutris, Wine, Winetricks, and Steam installer support
- Added GitHub Actions build, checksum, artifact, and configuration testing
